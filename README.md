## What Calyst Strap includes

- Account management and Roblox launch controls.
- Fast Flags import, compatibility review and application.
- Optional skins, asset customisation and engine settings.
- Window grid tools, memory controls and Auto Rejoin.
- Interface themes, app updates and release notes.

Flag compatibility, available assets and visual effects depend on the Roblox version and experience. An FPS increase is not guaranteed.
